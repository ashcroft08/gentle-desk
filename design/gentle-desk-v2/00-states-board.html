Per-chat states (direction A)

The main screens stay silent: a state appears only as the small mark at the end of a chat row, only when that chat has one. Every mark has its own shape, so color is never the only signal; the grayscale column proves it. Each mark also carries a text name for screen readers and a tooltip. All icons come from Lucide (ISC license), inlined as SVG.

New workspace: the menu

Choose: a folder dialog opens; the folder becomes a workspace and a new chat opens in it. Create: the user picks the location and the name, the folder is created, becomes a workspace and a new chat opens in it.

What a workspace without chats looks like

An added folder stays in the list even if its chat is never used; it simply has no chats yet. It is kept by gentle-desk, not by gentle-shell.
