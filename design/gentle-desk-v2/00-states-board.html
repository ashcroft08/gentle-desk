Per-chat states (shared by all three directions)

The main screens stay silent: a state appears only as the small mark at the end of a chat row, only when that chat has one. Every mark has its own shape, so color is never the only signal; the grayscale column proves it. Each mark also carries a text name for screen readers and a tooltip.
