Direction F · the Profile tab

A third tab beside Chat and Helpers: this chat's profile as a view

Helpers is a view of this chat's helpers, so the profile is a view of this chat's profile. The tab is always there, always says which profile this chat runs and in whose scope, and edits it in place — no overlay, no second window. The view is one accordion: Profile (the switch), Agents, Fallback chain, Pin, and a footer with the terminal's three outcomes. Settings keeps the global list; the chat keeps the three actions.
