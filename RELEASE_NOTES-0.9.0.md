What's new in 0.9.0
- **Settings opens on General, a new page that checks the machine.** One row each for Gentle Shell, pi, node and git, with whether it is installed, its version and, only when something is missing or could not be read, the exact command that fixes it. "Missing" and "could not read" are different words on purpose, and a missing git never stops the app.
- **The app tells you when an extension is behind.** The gear icon in the sidebar and the Updates entry in Settings get a dot, and the Extensions block names which one has an update. It checks with pi's own check, once the first chat is running; "Check again" runs it on demand. Before it has checked, the block says so instead of claiming everything is up to date.
- **Update commands follow your Home.** With "Separate" the buttons run `gentle-shell update`, `gentle-shell update --extensions` and `gentle-shell upgrade`; with "My pi" they run `pi update`, `pi update --extensions` and `pi install npm:gentle-pi@<version>`. Each button shows the exact command under it. With "My pi" it no longer opens `gentle-shell` and types `upgrade` into a chat, and it never installs a version it has not measured.
- **A "Close the chats" button in Updates.** The update buttons need every chat closed; the notice now has the button that does it in one step. Sessions are kept. A chat in the middle of a turn is never closed by it, and the pane says how many stay open and why.
- **Fixed: a closed chat could come back.** After closing a chat, a last message from its stopped process could re-create it and keep the open-chats count above zero, which blocked the update buttons. A chat you close now stays closed.
- **A clearer sidebar button and a wider new session.** The sidebar toggle is now a panel icon, and the box where you write in a new session is wider so the model, effort, folder and branch are not cut off.
- **Settings details.** Usage's plan no longer sits glued to the scrollbar.

Novedades en 0.9.0
- **Configuración abre en General, una página nueva que revisa la máquina.** Una fila para Gentle Shell, pi, node y git, con si está instalado, su versión y, solo cuando falta algo o no se pudo leer, el comando exacto que lo arregla. «Falta» y «No se pudo leer» son palabras distintas a propósito, y que falte git nunca frena la app.
- **La app te avisa cuando una extensión está atrasada.** El ícono de la tuerca de la barra lateral y la entrada Actualizaciones de Configuración muestran un punto, y el bloque de Extensiones nombra cuál tiene una actualización. Lo comprueba con el chequeo propio de pi, cuando arranca el primer chat; «Comprobar de nuevo» lo corre a pedido. Mientras no lo comprobó, el bloque lo dice en vez de afirmar que todo está al día.
- **Los comandos de actualizar siguen tu Home.** Con «Separado» los botones corren `gentle-shell update`, `gentle-shell update --extensions` y `gentle-shell upgrade`; con «Mi pi» corren `pi update`, `pi update --extensions` y `pi install npm:gentle-pi@<versión>`. Cada botón muestra debajo el comando exacto. Con «Mi pi» ya no abre `gentle-shell` ni escribe `upgrade` en un chat, y nunca instala una versión que no midió.
- **Un botón «Cerrar los chats» en Actualizaciones.** Los botones de actualizar necesitan todos los chats cerrados; el aviso ahora trae el botón que lo hace en un paso. Las sesiones se guardan. Un chat en medio de un turno no lo cierra, y el panel dice cuántos quedan abiertos y por qué.
- **Arreglado: un chat cerrado podía volver.** Después de cerrar un chat, un último mensaje de su proceso detenido podía volver a crearlo y mantener la cuenta de chats abiertos por encima de cero, lo que bloqueaba los botones de actualizar. Un chat que cerrás ahora queda cerrado.
- **Un botón de la barra lateral más claro y una sesión nueva más ancha.** El botón de la barra lateral ahora es un ícono de panel, y la caja donde escribís en una sesión nueva es más ancha para que no se corten el modelo, el esfuerzo, la carpeta ni la rama.
- **Detalles de Configuración.** El plan de Uso ya no queda pegado a la barra de desplazamiento.
